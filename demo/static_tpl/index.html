Gated Topological Correction of Stripe Artefacts in Brain MRI

Dr Ponraj Asirwadam Paulraj · Prof. Muthu Ramachandran

A 3D U-Net segments the tumour. A topological score decides whether the scan has a stripe artefact; only then is the correction applied. Results are pre-computed with the same code and settings as the paper.

The flag says whether a stripe artefact was found and corrected. It does not say whether the AI segmentation is correct. Threshold fitted on 12 training volumes; on 30 held-out volumes the flag fired on no clean scan and on every simulated stripe.

Roadmap: from public data to hospital scans (not yet done)

This demo uses the public BraTS-derived data, already converted, skull-stripped and aligned. Hospital scans need the standard steps first:

DICOM → NIfTI (dcm2niix) → select FLAIR → skull stripping (e.g. HD-BET or SynthStrip) → align to 1 mm (BraTS pre-processing) → our gated topological correction → any segmentation model (this U-Net, or a stronger one such as nnU-Net).

The correction works on the image before the model, so it does not depend on this U-Net. On hospital data the artefact threshold would be re-fitted on clean local scans with the same rule. None of this has been validated on hospital scans yet; that is the planned next step with clinical partners.

Research prototype — not for clinical use. All artefacts shown are simulated; the method has not been validated on real hospital data. Model: MONAI 3D U-Net trained on 60 MSD volumes (FLAIR).
